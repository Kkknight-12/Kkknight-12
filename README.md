# Hi, I'm Mayank 👋

I build interactive web experiences and visual learning tools. I enjoy making ideas tangible in the browser—whether that's a miniature weather scene, a flowing koi illustration, or an algorithm you can follow one step at a time.

[Explore DevProjects](https://dev-projects-hq.vercel.app/) · [Visit my portfolio](https://mayank-portfolio-seven.vercel.app/)

## What I'm building

- **Creative browser experiments** with Canvas, layered artwork, animation and scroll-driven interactions.
- **DSA learning tools** that connect changing data, code and explanations in Hindi and English.
- **DevProjects**, a home for practical developer learning, project context and useful resources.

## Tools I work with

- **Web foundations:** HTML, CSS, JavaScript and TypeScript.
- **Interfaces:** React, Next.js and Tailwind CSS.
- **Visual interaction:** Canvas 2D, Framer Motion and Shiki for code highlighting.
- **Development:** Git, npm, source inspection, builds and focused tests.

## How I learn

I learn by building practical projects: start with a concrete problem, make a working version, check its behavior, then improve it. I'm strengthening my JavaScript fundamentals, DSA reasoning and React/Next.js skills through that process.

I want the lessons from real bugs, design choices and experiments to become useful examples and explanations. DevProjects is where I'm bringing that learning and project work together.
